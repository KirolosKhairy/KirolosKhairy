## 1. Краткий обзор (Executive Summary)

В результате анализа `network.pcap` обнаружены убедительные признаки работы вредоносного ПО удалённого доступа **STRRAT** на рабочей станции **DESKTOP-SKBR25F** с внутренним IPv4-адресом **172.16.1.66** и учётной записью Windows **ccollier**.

**30 июля 2024 года в 02:40:05 UTC** рабочая станция установила TCP-соединение с внешним сервером **141.98.10.79:12132**. В **02:40:07 UTC** она передала строку `ping|STRRAT|...`, содержащую идентификатор клиента, имя хоста, имя пользователя, ОС и другие характеристики. Такие сообщения повторялись примерно каждые пять секунд до конца записи. Зафиксировано **102 сообщения STRRAT**.

Непосредственно перед первым сообщением STRRAT станция выполнила HTTP-запрос к `http://ip-api.com/json/` и получила сведения о внешнем IP-адресе и географическом расположении. Это согласуется с передаваемым в сообщениях агента значением `US:United States`. Сервис `ip-api.com` **не является сам по себе вредоносным индикатором**.

### Фрагмент сетевого доказательства

В кадре **9119** передана строка:

```text
ping|STRRAT|1BE8292C|DESKTOP-SKBR25F|ccollier|Microsoft Windows 11 Pro|64-bit|Windows Defender||1.6|US:United States|Not Installed|1 Sec
```

По результатам анализа соединения `172.16.1.66:49754 ↔ 141.98.10.79:12132` в обратном направлении обнаружены TCP ACK без прикладной полезной нагрузки. До начала соединения наблюдались запросы DNS к `github.com`, `repo1.maven.org` и `objects.githubusercontent.com`, но их роль в заражении **не подтверждена**, поэтому эти домены не внесены в список вредоносных IOC.
