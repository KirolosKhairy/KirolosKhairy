## 🚀 Featured Projects

### 🔬 TRACE — DFIR Investigation Workstation

An automated workstation prototype for investigating information security incidents.

- Collection and analysis of Windows digital artifacts
- Evidence integrity verification using **SHA-256**
- Case management and investigation activity logging
- HTML/PDF report generation
- Malware-infection investigation scenario

**Technology:** `C#` `.NET 8` `WinForms` `SQLite` `JSON` `SHA-256` `QuestPDF`

> Repository link will be added once the project repository is finalized.
