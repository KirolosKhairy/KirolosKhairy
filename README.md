### 🔬 TRACE — DFIR Investigation Workstation

**Automated workstation prototype for information security incident investigations.**

- Collection and analysis of Windows digital artifacts
- Artifact integrity verification using **SHA-256**
- Case management
- Investigation activity logging
- HTML / PDF reporting
- Malware Infection investigation scenario

**Stack:** `C#` `.NET 8` `WinForms` `SQLite` `JSON` `SHA-256` `QuestPDF`
